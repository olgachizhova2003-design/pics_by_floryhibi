Первый запуск

Вы скачали TavoAI и видите пустое приложение. Это нормально: Таво — это «оболочка». Модели, ботов и пресеты вы подключаете сами. Ниже — порядок, в котором это удобнее всего делать.

  1. Подключите модель — купите ключ у провайдера и добавьте его в API connections. Без этого бот не ответит ни слова.
  2. Заполните персону — кто вы в ролевой.
  3. Скачайте бота (персонажа) и импортируйте его.
  4. Поставьте пресет и его регексы — они отвечают за стиль и качество ответов.
  5. По желанию: Summary (долгая память), генерация картинок, плагины.

Меню Таво (на телефоне — раздел More). ① API connections — подключение моделей. ② Presets, Lorebooks, Regex — всё, что влияет на ответы. ③ Long-term memory — это и есть Summary.

Провайдер и ключ

Провайдер продаёт доступ к моделям (Claude, Gemini, GPT, DeepSeek и другим). Вы платите ему, получаете API-ключ и вставляете его в Таво.

Есть два типа оплаты. Подписка: фиксированная сумма в месяц. PayAsYouGo: платите за каждое сообщение, сколько наролили — столько и списали.

LiteRouterподписка
literouter.com

Один из самых дешёвых провайдеров, подписки разные. Чем дешевле подписка, тем глупее модель (по наблюдениям автора гайда). Из России — только через посредника.

OpenRouterPayAsYouGo
openrouter.ai

Доступ к официальным моделям. Очень дорого, подписок нет: ролишь — платишь. Без посредника не оплатить.

Rout.Myподписка
rout.my

Качество моделей близко к OpenRouter. Подписка с Opus стоит 4900 — дорого. В последнее время провайдер иногда лежал.

ElectronHubподписка + PayAsYouGo
electronhub.ai

Есть оба варианта оплаты. Автор гайда сама не пользовалась, но его хвалят: ложится редко, качество моделей хорошее, подписки дороговаты.

OpenRouter и VPN. Если вы из России, заходите на сайт OpenRouter и ролите в Таво только с включённым VPN. Зайдёте без VPN — получите бан, и деньги никто не вернёт.

Если вы из России, для оплаты почти всех провайдеров нужен посредник: российские карты они не принимают.

Как добавить ключ в Таво

API connections → кнопка Create в правом верхнем углу. Выберите New API connection. Router нужен, только если хотите объединить несколько подключений.

Для OpenRouter есть готовая платформа в списке. Для LiteRouter, Rout.My, ElectronHub и большинства других выбирайте один из вариантов Custom. Чаще всего подходит Custom (OpenAI-compatible); если провайдер в инструкции пишет Anthropic- или Gemini-compatible, берите его.

⑤ API base URL — адрес из личного кабинета провайдера (обычно заканчивается на /v1). ⑥ API key — ваш ключ. ⑦ Model — список подтянется сам, выберите модель. ⑧ Save.

Никому не показывайте свой ключ и не выкладывайте скриншоты с ним: по нему можно потратить ваши деньги.

Настройки модели

У каждого подключения есть свои параметры генерации. Откройте подключение в API connections и нажмите шестерёнку в правом верхнем углу.

Слева — шестерёнка в Edit API (ключ замазан). Справа — API Parameters: здесь настройки автора гайда для Claude Opus.

  • Temperature — «креативность». Ниже — предсказуемо и по сценарию, выше — фантазийно, но больше бреда.
  • Top-P — насколько разнообразны варианты, из которых модель выбирает слова.
  • Frequency penalty — штраф за повтор слов. Выше — богаче лексика, меньше одинаковых фраз.
  • Presence penalty — выше значит модель охотнее уходит в новые темы вместо того, чтобы крутиться вокруг одной.
Что важнее. Параметры подключения перекрывают глобальные (Model settings в меню). Если здесь ничего не задано, берутся глобальные. Хороший пресет обычно сам подсказывает значения.

В глобальных Model settings также есть Memory — сколько последних сообщений видит модель (больше — лучше помнит, но дороже), и Max response tokens — максимальная длина ответа (слишком мало — ответ оборвётся).

Персона

Персона — это вы в ролевой. Бот читает её, чтобы знать, к кому обращается: имя, внешность, характер, роль в сюжете.

Personas → Create. Персон может быть много — под разные истории. Отметка Default показывает, какая включена.

Как заполнить

  • Имя и возраст. Бот будет обращаться к вам по имени.
  • Внешность. Рост, волосы, глаза, стиль одежды — 2–4 предложения, без романа.
  • Характер. Пара ключевых черт и как вы обычно себя ведёте.
  • Роль в сюжете. Кто вы этому персонажу: студентка, соседка, коллега. Удобно делать отдельную персону под каждого бота.
Пишите персону на английском, даже если ролите на русском: английский текст занимает меньше токенов, а значит каждое сообщение дешевле.

Где брать ботов

Бот (персонаж, карточка) — это файл PNG или JSON с описанием героя, первым сообщением и иногда лорбуком.

Где искать

  • janitorai.com — огромный выбор, но качество очень разное: роза среди навоза. Скачивать оттуда нужно через datacat (ниже).
  • Telegram-каналы ботоделов. Боты этих авторов — с очень длинными и живыми ролевыми:
    t.me/SinnersBasement t.me/murxaibot t.me/chromek1djai

Как скачать бота с JanitorAI

  1. Откройте datacat.run/fresh.
  2. В меню Characters нажмите Explore Characters и введите имя бота.
  3. На странице бота нажмите Download и выберите PNG (или ZIP, если хотите сразу с лорбуками и скриптами).

Как добавить в Таво

Characters → Create → импорт файла. Скачанный PNG можно импортировать как есть — карточка зашита прямо в картинку.

Пресеты

Пресет — набор инструкций для модели: как писать, от чьего лица, какой длины, что можно и что нельзя. Один и тот же бот на разных пресетах звучит совершенно по-разному.

SillyTavern и Таво. Пресеты из SillyTavern спокойно встают в Таво. А вот пресеты из Таво встают в SillyTavern не всегда.

Где искать

  • Официальный Discord TavoAI — discord.gg/rmbKcMeGn. Ветка lorebook-presets-regex — пресеты на английском, ветка 世界书-预设-正则分享 — на китайском. Всё сделано именно под Таво.
  • Discord ✦AI Presets✦ — discord.gg/PpHrcJGVH. Раздел presets: пресеты на английском и русском, для Таво и SillyTavern, плюс промпты, расширения и гайды.
  • Telegram-каналы русскоязычных креаторов. Хвалят пресеты:
    t.me/sillykamoi t.me/ah_ah_shino4ka
    У sillykamoi есть отличный пресет под Claude и отдельный под GPT. Пресет Шино хорошо работает на Gemini.

Слева — нужные ветки в Discord TavoAI. Справа — раздел presets в ✦AI Presets✦.

Как понять, какой пресет вам подходит

  • Под какую модель он писался. Пресет под Claude на Gemini может работать хуже, и наоборот. Автор обычно пишет это в описании.
  • Язык. Русский пресет обычно даёт более живой русский текст.
  • Плашки или чистый текст. Некоторые пресеты добавляют HTML-плашки (статусы, телефон, мысли). Красиво, но тратит токены. Если устали — берите пресет без них.
  • Попробуйте на одном и том же боте. Сыграйте 5–10 сообщений на двух пресетах и сравните — это быстрее любых обзоров.

Установка и тогглы

Presets → Create → импорт файла. Нажмите на пресет, чтобы открыть его. Внутри пресет разбит на тогглы. Переключатели включают и выключают отдельные тогглы (например, плашки или «мысли»). Карандаш — редактировать текст тоггла. Не забудьте Save.

Регексы

Регекс (regex) — правило «найди и замени» для текста сообщений. Модель пишет служебный текст, а регекс превращает его в красивую плашку, прячет лишнее или чистит мусор.

Модель написала<status>Настроение: злится | Время: 23:10</status>
Вы видите
Настроение: злится · 23:10
  • Регексы идут в комплекте с пресетом. Если пресет рисует плашки, автор почти всегда выкладывает рядом файл регексов. Без них вы увидите сырые теги.
  • Импортируйте их вместе: пресет — в Presets, регексы — в Regex.
  • Не включайте регексы от разных пресетов одновременно — они могут конфликтовать.

Regex → Create → импорт. Группы регексов; откройте группу, чтобы включить или выключить отдельные правила.

Лорбуки

Лорбук — справочник мира: места, второстепенные персонажи, правила магии. Записи подставляются в запрос, только когда в чате звучит их ключевое слово, поэтому не тратят контекст зря.

Lorebooks → Create → импорт. Многие боты приходят со своим лорбуком — он подключится сам при импорте карточки.

Summary (память)

Модель видит только последние сообщения (см. Memory в настройках модели). Всё, что было раньше, она забывает. Summary — это краткий пересказ сюжета, который Таво пишет автоматически и подкладывает модели в каждый запрос.

В Таво это раздел Long-term memory.

  • ① Auto summarize — каждые N сообщений Таво обновляет пересказ. 0 — выключено.
  • ② Memory limit — сколько строк памяти хранить.
  • ③ Summary prompt — инструкция, по которой пишется пересказ. Можно попросить писать по-русски и отмечать важные факты.
  • ④ Injection position / prompt — куда и в каком виде пересказ вставляется в запрос.
Зачем это нужно. В длинной ролевой без Summary бот забывает имена, обещания и события. С ним можно держать Memory поменьше и экономить, а сюжет не потеряется. Пересказ можно открыть в чате и поправить вручную.
ВАЖНО: Summary можно не использовать вообще. На сайте Tavo Hub есть плагины, которые собирают лорбук по вашему РП-чату. В этом случае Summary вы выключаете (Auto summarize = 0) и используете плагин.

Dedicated API вверху позволяет писать пересказ отдельной, более дешёвой моделью.

First launch

You installed TavoAI and the app is empty. That's expected: Tavo is a shell. You bring the models, bots and presets yourself. Here is the order that works best.

  1. Connect a model: buy a key from a provider and add it under API connections. Without it the bot can't reply at all.
  2. Fill in your persona: who you are in the roleplay.
  3. Download a bot (character) and import it.
  4. Install a preset and its regexes. They control style and reply quality.
  5. Optional: Summary (long-term memory), image generation, plugins.

Tavo's menu (on a phone it's under More). ① API connections: your models. ② Presets, Lorebooks, Regex: everything that shapes replies. ③ Long-term memory is the Summary.

Chapter 2 / 11

Provider & key

A provider sells access to models (Claude, Gemini, GPT, DeepSeek and others). You pay them, get an API key, and paste it into Tavo.

There are two ways to pay. A subscription is a fixed monthly price. Pay-as-you-go charges for every message you send.

LiteRoutersubscription
literouter.com

One of the cheapest providers, with several plans. In the author's experience, the cheaper the plan, the dumber the model. Paying from Russia needs a middleman.

OpenRouterpay-as-you-go
openrouter.ai

Access to official models. Very expensive, no subscriptions: you pay for every reply. Can't be paid from Russia without a middleman.

Rout.Mysubscription
rout.my

Model quality close to OpenRouter. The plan with Opus costs 4900 RUB, which is a lot. It has had outages recently.

ElectronHubsubscription + pay-as-you-go
electronhub.ai

Offers both. The author hasn't used it herself, but people praise it: rarely down, good model quality, somewhat pricey plans.

OpenRouter and VPN. If you are in Russia, open the OpenRouter site and roleplay in Tavo only with a VPN on. Without it you can get banned, and nobody will refund your money.

From Russia, almost every provider needs a payment middleman, since Russian cards aren't accepted.

Adding your key to Tavo

API connections → the Create button at the top right. Choose New API connection. A router is only for combining several connections.

OpenRouter has its own entry in the list. For LiteRouter, Rout.My, ElectronHub and most others, pick one of the Custom options. Usually that's Custom (OpenAI-compatible); if your provider's instructions say Anthropic- or Gemini-compatible, use that one.

⑤ API base URL: the address from your provider's dashboard (usually ends in /v1). ⑥ API key: your key. ⑦ Model: the list loads by itself, pick one. ⑧ Save.

Never share your key or post screenshots that show it: anyone with it can spend your money.

Chapter 3 / 11

Model settings

Every connection has its own generation parameters. Open the connection in API connections and tap the gear at the top right.

Left: the gear in Edit API (key hidden). Right: API Parameters, showing the author's settings for Claude Opus.

  • Temperature: creativity. Lower is predictable and on-script, higher is imaginative but drifts.
  • Top-P: how varied the word choices the model picks from are.
  • Frequency penalty: a penalty for repeating words. Higher means richer vocabulary and fewer repeated phrases.
  • Presence penalty: higher makes the model more willing to move to new topics instead of circling one.
Which wins. Connection parameters override the global ones (Model settings in the menu). If nothing is set here, the global values apply. A good preset usually suggests values.

Global Model settings also hold Memory, how many recent messages the model sees (more recall, higher cost), and Max response tokens, the longest a reply can be (too low cuts replies off).

Persona

A persona is you in the roleplay. The bot reads it to know who it's talking to: name, looks, personality, role in the story.

Personas → Create. You can keep many personas for different stories. Default marks the active one.

What to write

  • Name and age. The bot will call you by name.
  • Looks. Height, hair, eyes, clothing style. Two to four sentences, not a novel.
  • Personality. A couple of key traits and how you usually act.
  • Role in the story. Who you are to this character: a student, a neighbour, a coworker. A separate persona per bot works well.
Write your persona in English, even if you roleplay in another language: English text takes fewer tokens, so every message costs less.

Presets

A preset is a set of instructions for the model: how to write, from whose point of view, how long, what's allowed. The same bot sounds completely different on different presets.

SillyTavern and Tavo. SillyTavern presets work in Tavo without trouble. Tavo presets don't always work in SillyTavern.

  • ✦AI Presets✦ Discord: discord.gg/PpHrcJGVH. The presets channel has English and Russian presets for Tavo and SillyTavern, plus prompts, extensions and guides.
  • Russian creators on Telegram. Well-liked presets:

Left: the channels in the TavoAI Discord. Right: the presets channel in ✦AI Presets✦.

How to pick a preset

  • Which model it targets. A Claude preset may do worse on Gemini, and the other way round. Authors usually say so in the description.
  • Language. A preset written in your language usually gives more natural prose in it.
  • Panels or plain text. Some presets add HTML panels (status, phone, thoughts). They look nice but cost tokens. If you're tired of them, use a preset without.
  • Test on one bot. Play 5–10 messages on two presets and compare. It's faster than any review.

Installing and toggles

Presets → Create → import a file. Click a preset to open it. A preset is split into toggles. The switches turn individual toggles on and off (panels, thoughts and so on). The pencil edits a toggle's text. Remember to press Save.

Regexes

A regex is a find-and-replace rule for message text. The model writes tagged text, and the regex turns it into a styled panel, hides extras or cleans up junk.

The model wrote<status>Mood: angry | Time: 23:10</status>
You see
Mood: angry · 23:10
  • Regexes come with the preset. If a preset draws panels, the author almost always posts a regex file next to it. Without it you'll see raw tags.
  • Import both: the preset into Presets, the regexes into Regex.
  • Don't enable regexes from different presets at once. They can clash.

Regex → Create → import. Regex groups; open one to toggle individual rules.

Chapter 9 / 11

Summary (memory)

The model only sees the most recent messages (see Memory in model settings) and forgets everything before. Summary is a short recap of the story that Tavo writes automatically and adds to every request.

In Tavo this lives under Long-term memory.

  • ① Auto summarize: Tavo updates the recap every N messages. 0 turns it off.
  • ② Memory limit: how many memory lines to keep.
  • ③ Summary prompt: the instruction used to write the recap. You can ask for your language and for key facts to be noted.
  • ④ Injection position / prompt: where and how the recap is inserted into the request.
Why it matters. In a long roleplay without a summary, the bot forgets names, promises and events. With one, you can keep Memory lower and save money without losing the plot. You can open the recap in chat and edit it by hand.
IMPORTANT: you don't have to use Summary at all. Tavo Hub has plugins that build a lorebook from your roleplay chat. If you use one, turn Summary off (Auto summarize = 0) and let the plugin do the job.

Dedicated API at the top lets a separate, cheaper model write the recap.

下一章服务商与密钥

第 2 / 11

服务商与密钥

服务商出售模型（Claude、Gemini、GPT、DeepSeek 等）的使用权限。付费后你会得到一个 API 密钥，把它填进 Tavo 即可。

付费方式有两种：订阅制，每月固定费用；按量付费（PayAsYouGo），发多少消息扣多少钱。

LiteRouter订阅制
literouter.com

最便宜的服务商之一，有多档订阅。据作者观察，订阅越便宜，模型越笨。从俄罗斯付款需要中间人代付。

OpenRouter按量付费
openrouter.ai

提供官方模型。非常贵，没有订阅，用多少付多少。从俄罗斯无法直接付款。

Rout.My订阅制
rout.my

模型质量接近 OpenRouter。含 Opus 的订阅 4900 卢布，较贵。最近偶尔宕机。

ElectronHub订阅 + 按量
electronhub.ai

两种方式都有。作者本人没用过，但口碑不错：很少宕机，模型质量好，订阅略贵。

OpenRouter 与 VPN。如果你在俄罗斯，访问 OpenRouter 网站和在 Tavo 中使用时必须开启 VPN。不开 VPN 可能被封号，钱也不会退。

在俄罗斯，几乎所有服务商都需要中间人代付，因为不接受俄罗斯银行卡。

如何在 Tavo 中添加密钥

API connections → 右上角 Create。 选择 New API connection。Router 仅用于合并多个连接。

OpenRouter 在列表中有专门选项。LiteRouter、Rout.My、ElectronHub 等大多数服务商请选择一个 Custom 选项。通常是 Custom (OpenAI-compatible)；如果服务商说明写的是 Anthropic 或 Gemini 兼容，就选对应的。

⑤ API base URL：服务商后台给出的地址（通常以 /v1 结尾）。⑥ API key：你的密钥。⑦ Model：列表会自动加载，选择模型。⑧ Save。

不要把密钥给别人，也不要发带密钥的截图：别人可以用它花你的钱。

第 3 / 11

模型设置

每个连接都有自己的生成参数。在 API connections 中打开连接，点击右上角的齿轮。

左：Edit API 中的齿轮（密钥已遮挡）。右：API Parameters，图中是作者为 Claude Opus 设置的参数。

  • Temperature：“创造力”。低则稳定贴合剧本，高则天马行空但容易跑偏。
  • Top-P：模型可选词语的多样程度。
  • Frequency penalty：对重复用词的惩罚。越高用词越丰富，重复句子越少。
  • Presence penalty：越高，模型越愿意转向新话题，而不是绕着一个话题打转。
优先级。连接参数会覆盖全局参数（菜单中的 Model settings）。这里未设置时使用全局参数。好的预设通常会给出推荐值。

全局 Model settings 中还有 Memory（模型能看到的最近消息条数，越多记得越清楚但越贵）和 Max response tokens（回复最大长度，太小会被截断）。

上一章正则下一章总结（记忆）

第 9 / 11

总结（记忆）

模型只能看到最近的消息（见模型设置中的 Memory），更早的内容会被遗忘。总结（Summary）是 Tavo 自动写的剧情摘要，每次请求都会附带给模型。

在 Tavo 中对应 Long-term memory。

  • ① Auto summarize：每 N 条消息更新一次摘要，0 为关闭。
  • ② Memory limit：保存多少行记忆。
  • ③ Summary prompt：生成摘要所用的指令，可以要求用中文、标注重要事实。
  • ④ Injection position / prompt：摘要插入请求的位置和格式。
为什么需要。长剧情不开总结，角色会忘记名字、承诺和事件。开启后可以把 Memory 调小省钱，剧情也不会丢。摘要可以在聊天中打开手动修改。
重要：总结功能可以完全不用。Tavo Hub 上有插件会根据你的角色扮演聊天自动整理世界书。使用这类插件时，请关闭总结（Auto summarize = 0），改用插件。

顶部的 Dedicated API 可以让另一个更便宜的模型来写摘要。
